# Get started

A Trinet camera works in two ways:

<div class="grid cards" markdown>

-   :material-sd:{ .lg .middle } **On its own, to a memory card**

    ---

    Insert a microSD card, power the camera, press the button. No phone or computer needed —
    ideal for long sessions and field data collection.

    [:octicons-arrow-right-24: Record your first take](first-recording.md)

-   :material-usb:{ .lg .middle } **Tethered, over USB**

    ---

    Plug the camera into an Android phone (Trinet app), a computer or — for Trinet Mono — an
    iPhone, with live preview and recording on the device.

    [:octicons-arrow-right-24: Use as a USB camera](usb-camera.md)

</div>

## What you need

- [x] A **Trinet camera** and its USB-C cable.
- [x] A **microSD card** for standalone recording — exFAT formatted, a fast endurance card, 64 GB
      or more (128 GB or more for stereo). See [Memory cards](../power-and-care/memory-cards.md).
- [x] **Power**: a USB power bank or charger that supplies 5 V at 1 A or more. Some power banks
      switch off at the camera's low power draw — see [Tested power banks](../power-and-care/power-banks.md).
- [ ] *Optional:* an Android phone with the [Trinet app](../app/index.md) — for live preview,
      settings, firmware updates and watching kits in the field.
- [ ] *Optional:* a computer with the [Python toolkit](../toolkit/index.md) to inspect, visualize
      and export recordings.

## The basics

| | |
|---|---|
| **Button** | Tap to start or stop recording. Other gestures pair kit cameras — see [Button](button.md). |
| **Status light** | Shows what the camera is doing — see [LED indications](led-indications.md). |
| **Mode** | A card inserted → records to the card. No card → USB camera. See [Recording modes](modes.md). |
| **Lens** | The focus is set at the factory. Pull the protective cap straight off; never twist the lens. |

!!! warning "Before you record"
    Remove the lens cap by pulling it straight off. Do not rotate or screw the lens — that changes the
    factory-set focus.
